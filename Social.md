# gNewSense Evolution - Social Media Management Guidelines

This document contains the official operational instructions for managing project media broadcast networks. Because the project founder is under 18, **adult maintainers or parent administrators must register, own, and moderate these channel endpoints to comply with terms of service rules.**

All content published to these networks must remain completely silent (no voice commentary) and focus entirely on visual operating system demonstrations, code layouts, and text-guided configurations.

---

## 📢 1. Broadcast Feed Directories

### 📺 YouTube Video Log Channel 🔄
*   **Official Handle:** `@gnewsenselinux`
*   **Channel Name Style:** gNewSense Evolution - Development Logs
*   **Content Policy:** Strict screen-recordings only. Use text annotation overlays or video cards for explanations. Audio tracks must pull strictly from the free-licensed YouTube Audio Library. No voice recording or face-camera capture allowed.

### 🐦 Micro-Blog & Mastodon Broadcast Feeds
*   **Official Twitter Handle:** `@gnewsenselinux`
*   **Official Mastodon Handle:** `@gnewsense`
*   **Content Policy:** Text-only update matrices written in clean Title Case format. Focus on code snippets, rsync deployment status readouts, and short 5-second workspace animation layout loop clips (GIFs).

---

## 🛠️ 2. Formatting Rules for Media Managers
*   **Text Standard:** Always use clean Title Case descriptions (e.g., `gNewSense Personal Desktop`). Never use full caps in post text headers to ensure readability and professional presentation.
*   **Privacy Guardrail:** Never publish personal photos, developer ages, locations, or voice tracks. Keep the content strictly technical and centered around our GitHub build profiles and templates.
