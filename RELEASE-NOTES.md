# gNewSense Evolution v5.0 (Forky Base) - Official Release Notes

The gNewSense Core Team is proud to announce the official deployment milestone of **gNewSense Evolution v5.0**. This release builds natively on the **Debian 14 (Forky)** package baseline, optimizing stability, system customization, and backwards compatibility without rolling-release software breakage.

---

## 🚀 Key Architectural Breakthroughs

### 🌟 1. Native Multiarch i686 Execution Layer
To guarantee absolute software preservation, all 64-bit (`amd64`) system builds feature native **Debian Multiarch integration enabled by default**. The package execution engines automatically support legacy 32-bit (`i386`) software, retro binaries, and vintage runtime toolchains without requiring any manual setup.

### 🐧 2. Performance Kernel Selections
Boot selection menus are armed with the low-latency **Linux Zen Kernel**, providing advanced task scheduling loops and optimized memory caching layers to maximize processing speeds across high-density desktop environments.

### 🔒 3. Total Desktop Session Sandboxing
With up to 34 window managers packed onto a single image file, all interface parameters, user shortcuts, and layout variables are strictly sandboxed inside independent skeleton paths (`/etc/skel/.config/`). Global directories remain unpolluted.

## 💾 Official Release Manifest

### 🌟 Flagship Editions
*   **Workstation:** Pure flagship experience running strictly on modern GNOME (GTK4). Powered by GDM.
*   **Personal Desktop:** Infinity customization layout powered by Qt6 / KDE Plasma. Powered by SDDM.
*   **KDE Theme Edition:** Premium layouts mimicking WhiteSur, Sonoma, Ventura, Tahoe, Windows 11, and Skeuo Silver.
*   **Devuan:** Init-freedom option running 7 major desktops entirely free of systemd dependencies. Powered by LightDM.
*   **FreeOnly:** 100% Free Software compliant workstation bundling 15 desktops over a strict `linux-libre` kernel.

### 🖥️ Specialized Spins
*   **gNewSense Spin:** The ultimate computing playground packed with 21 full desktop environments.
*   **Polina Spin:** Experimental hybrid Qt workspace combining an LXQt backend with a KWin compositor layer.
*   **Tiling WM Spin:** Keyboard-driven power toolbox loaded with 21 dynamic and manual tiling managers.
*   **Stacking WM Spin:** The ultimate floating desktop workspace featuring 34 vintage and minimal stacking managers.

### 📦 Base Spins (Multi-Desktop GUI Only)
*   Upstream-aligned GUI-only setups tracking Kali Linux (10 Desktops), Parrot OS (5 Desktops), PureOS (2 Desktops), Pop!_OS (2 Desktops), Kubuntu, LinuxMCE, BackBox, MXLinux, Q4OS, and antiX.
